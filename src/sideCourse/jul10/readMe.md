categories of API
- open/public ---- publicly available, little to no restriction
- private --- mostly consumed within their own system
- partner --- 


Types of API
- SOAP - Simple object access protocol uses XML
- REST - Representational state transfer

Rest is built on top of plain HTTP. uses JSON

XML -> Xtensible markup language
HTTP -> Hyper text transfer protocol. Set of rules which allows browser to communicate to sever
JSON -> JavaScript object notation


Rest architectural constraints
- Client-server
- statelessness 
- Layered system
- cacheable
- uniform interface

HTTP methods
- GET
- POST
- PUT --- replace the whole resource
- PATCH --- update some field in the resource
- DELETE
- QUERY
